
# FASTA File Parser

## Description
A beginner-friendly bioinformatics project using
Python and Biopython to analyze DNA sequences
stored in a FASTA file.

## Features
- Extracts sequence IDs
- Calculates sequence length
- Calculates GC content percentage
- Supports multiple FASTA sequences

## Technologies Used
- Python
- Biopython

## Input
A FASTA file containing DNA sequences.

## Output
Sequence ID, sequence length, and GC content (%).

## How to Run
Install Biopython:
pip install biopython

Run the script:
python fasta_parser.py

## Project Type
Beginner Bioinformatics Project
